# migrations/local — ไฟล์ที่รันบนเครื่องตัวเองเท่านั้น

ไฟล์ในโฟลเดอร์นี้ **ห้ามรันกับฐานจริง**

ฐาน LINE ของจริง (Neon) มีเจ้าของเป็นบริการฝั่ง LINE webhook ซึ่งสร้างตาราง
`line_groups` / `line_messages` ไว้แล้วด้วย schema ของตัวเอง ไฟล์ในนี้สร้าง
ตารางชื่อเดียวกันแบบย่อ เท่าที่ backend ตัวนี้ "อ่าน" เพื่อให้ console เปิดขึ้นมา
ได้ตอนพัฒนาโดยไม่ต้องต่อ Neon ถ้าเผลอรันกับฐานจริงแล้วชื่อชนกัน จะกลายเป็นว่า
เขียนทับของที่บริการอื่นเป็นเจ้าของ

| ไฟล์ | รันกับฐาน | ใช้ตอน |
| --- | --- | --- |
| `line_local.sql` | `LINE_DATABASE_URL` (คอนเทนเนอร์ `nextlink-line-db`) | พัฒนาบนเครื่องตัวเอง |

ส่วนไฟล์ที่อยู่ใน `migrations/` ชั้นบน (`init.sql`, `electives.sql`,
`elective_seed.sql`, `security.sql`) เป็น schema ของฐาน `NEXTLINK_DATABASE_URL`
ซึ่ง backend ตัวนี้เป็นเจ้าของ รันได้ทั้งบนเครื่องตัวเองและบนฐานจริง

ตาราง `line_group_reads` เป็นสถานะของ backend เอง (อ่านถึงไหนแล้ว) จึงอยู่ฝั่ง
`nextlink` และถูกสร้างโดย `init.sql` ไม่ใช่ไฟล์ในโฟลเดอร์นี้
