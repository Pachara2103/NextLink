# migrations/local — ไฟล์ที่รันบนเครื่องตัวเองเท่านั้น

ทุกไฟล์ในโฟลเดอร์นี้สร้างตารางที่ **มีอยู่แล้วบน Neon และมีเจ้าของเป็นบริการอื่น**
มันมีไว้เพื่อให้เปิด console บนเครื่องตัวเองได้โดยไม่ต้องต่อฐานจริงเท่านั้น

อย่ารันกับฐาน production — ไฟล์พวกนี้ทุกคำสั่งเป็น `CREATE TABLE IF NOT EXISTS`
จึงไม่ลบข้อมูลใคร แต่ตารางที่มันสร้างมีคอลัมน์น้อยกว่าของจริง ถ้าเผลอรันกับฐาน
ที่ยังไม่มีตารางนั้น (เช่นฐาน staging ใหม่) จะได้ตารางที่เขียนฝั่ง webhook ไม่ได้

| ไฟล์ | รันกับฐานไหน | สร้างอะไร |
|---|---|---|
| `line_local.sql` | `LINE_DATABASE_URL` บนเครื่องตัวเอง | `line_groups`, `line_messages` เท่าที่ `services/line.py` อ่าน |

## ที่ไม่ได้อยู่ในนี้ (ตั้งใจ)

- **`../line_group_reads.sql`** — ชื่อขึ้นต้นด้วย `line_` เหมือนกัน แต่เป็น
  **สถานะของ backend ตัวนี้เอง** (อ่านกลุ่มถึงไหนแล้ว) อยู่ฝั่งฐาน `nextlink`
  ไม่ใช่ฐาน LINE จึงต้องรันบน Neon ด้วย ดูคำอธิบายที่หัว `../init.sql`
