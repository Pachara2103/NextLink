- ผมลบ is_linked ออกจาก schemas ฝั่ง backend ให้คุณลบที่อื่นๆ ที่ยังมีอยู่ และให้เปลี่ยนการแสดงผลที่ใช้ is_linked แทนด้วย group_id แทน (ถ้ามี) เช่น is_linked=True คือ group_id ไม่เป็น  null
  ส่วนตรง update_information ที่ฝั่ง frontend ต้องส่ง group_data: dict[str, GroupInfo] มา ผมแก้ที่ backend ให้ is_linked -> has_company (คืออันที่ group_id เป็น null -> has_company = False) ให้คุณไปแก้ที่ frontend ใหส่ง has_company มาให้ถูกด้วยครับ (คือเอา group id ของ line ไปดูว่าใน company ไหนใช้แล้วยัง)
- หน้ากลุ่มไลน์และบริษัท ตรงกลุ่มไลน์ที่ผูกบริษัทแล้ว, กลุ่มไลน์ที่ยังไม่ได้ผูกบริษัท ผมแก้ชื่อเป็น บริษัทที่ผูกกลุ่มไลน์แล้ว, บริษัทที่ยังไม่ผูกกลุ่มไลน์ โดยให้แก้ไข card ที่แสดงภายในหัวข้อนี้ ดังนี้
  - ให้เอาชื่อที่บริษัทที่อยู่ข้างล่าง สลับที่กับชื่อกลุ่มไลน์ แล้วเปลี่ยนการแสดงผลทั้งกรณีที่ไม่มีชื่อกลุ่มไลน์ หรือบริษัทให้เหมาะสม รวมถึงเปลี่ยน icon ให้เหมาะกับกลุ่มไลน์ด้วย 
     โดย บริษัทที่ผูกกลุ่มไลน์แล้ว ให้แสดงเฉพาะ company ที่ group_id ไม่เป็น null และ บริษัทที่ยังไม่ผูกกลุ่มไลน์ แสดงเฉพาะ company ที่ group_id เป็น null
  - บริษัทที่ยังไม่ผูกกลุ่มไลน์ ให้เปลี่ยนปุ่ม เพิ่มบริษัท เป็น ผูกกลุ่มไลน์ เมื่อกดให้ขึ้น pop up แสดง list of group line name ที่ยังไม่มี company ไหนใช้เลย และในแต่ล่ะ group line in list ขวาสุดให้มีปุ่ม เลือก อยู่ให้ติ้กเลือกได้ โดยถ้าติ้กเลือกแล้วไปติ้กอันอื่น ให้ยกเลิกติ้กอันเก่าออก แล้าถ้า double click ให้ toggle ปุ่มเลือกครับ 
    และถ้ายังไม่เลือก group line อันไหน ให้ปุ่ม ยืนยัน disable ถ้าเลือกแล้วให้กดปุ่มยืนยันได้ครับ มีปุ่มยกเลิกให้ออกจากหน้านี้ได้ด้วย เมื่อกดยืนยันให้ใช้ companyService.link ครับ
